Install / 安装

四步装完，不用电脑

两个工具装法一样，装完只需要开一个「无障碍」权限。全程不需要 Root，也不需要连线。

  1. 01

    下载 APK

    点上面的下载按钮，文件会进手机的「下载」目录。用电脑下载也行，微信 / QQ / 数据线传过去都可以。

  2. 02

    允许安装未知来源

    点开文件安装。系统提示「禁止安装未知来源应用」时，点「设置」→ 允许当前浏览器或文件管理器 → 返回继续安装。 杀毒软件报「有风险」时选「继续安装」，这是自签名 APK 的正常提示。

  3. 03

    开启无障碍服务

    打开 App，点首页的「打开无障碍设置」→ 找到对应服务 → 开启 → 系统弹窗选「允许」。 回到 App 看到「已连接」就成功了。

  4. 04

    回游戏里用悬浮窗控制

    VClicker：先在你的游戏界面上逐点标记要点的位置，再从悬浮面板点「开始」。 纵横商界助手：手动进到「纵横商界」主界面，切回 App 开悬浮窗，再切回游戏点「开始」。

它们要什么权限、为什么

无障碍服务 需要
唯一的点击方式：把「点这里」翻译成系统手势。VClicker 只注入点击、不读屏幕内容；纵横商界助手会截屏，但只在本地按像素颜色判断界面。
悬浮窗 需要
在游戏上叠一个可拖动的开始 / 停止面板。助手还会在每次点击的位置闪一个红圈，方便你确认点得准不准。
通知 需要
前台服务保活提示，避免自动点击跑着跑着被系统清掉。
忽略电池优化 可选
不授权也能用，只是熄屏久了更容易被系统暂停。
网络 不需要
两个安装包里都没有 INTERNET 权限 —— 没有上报、没有统计、没有广告 SDK，数据不会离开手机。

FAQ / 常见问题

装之前你可能想知道的

安装时提示「有风险」/「未经安全检测」？

正常现象。APK 是自签名、没有上架任何应用商店，所以不会有厂商的安全认证和备案信息。点「继续安装 / 仍要安装」即可。

如果你比较谨慎，可以先断网再装：两个 App 都没有联网权限，断网安装不影响任何功能，装完再联网。

需要 Root 吗？需要电脑配合吗？

都不需要。全部基于安卓系统的无障碍服务（AccessibilityService）实现，用的是系统公开能力：截屏 + 注入点击手势。

也不用装框架、不用开 USB 调试。手机或模拟器（MuMu、雷电等）都可以。

会不会被封号？

有风险。这类工具本质上是模拟人手点击来做自动化，是否允许取决于游戏的用户协议。部分游戏会检测异常点击节奏并处罚。

建议只在单机、自建或小号场景使用，并控制运行时长与频率。因使用本站工具导致的账号、数据或财产损失，作者不承担责任。

无障碍权限会不会读到我的密码、聊天记录？

VClicker：只调用手势注入接口按坐标点击，不读取屏幕内容、不抓取界面文本。

纵横商界助手：会截屏，但图片只在内存里按像素颜色判断「当前是哪个界面」，不上传服务器、不会被读到屏幕上别的内容。只有你手动点「保存当前画面到相册」时才会写一张图，或异常停机时自动存一张到相册。

两者都没有 INTERNET 权限，装完可以把手机流量 / Wi-Fi 关掉验证。

挂机一会儿就自己停了？

大概率是保护机制在起作用，而不是卡死：连续约 1 分钟画面完全没变化、同一界面卡超过 3 分钟、连续 9 次点房间都没反应，都会主动停机。

打开 App 首页看日志最后几条，或看相册里自动保存的 异常_*.png。把那张图发给我，我按真实画面修识别规则。

手机 / 模拟器分辨率不一样，能用吗？

VClicker：点位是你在自己屏幕上取的，天生适配任意分辨率。

纵横商界助手：坐标按 1260×2800 量、再按屏幕宽高比例换算，9:16 和 9:20 都支持；不过「公司架构」的 3×3 房间格仍建议 9:20。模拟器设成 1080×2400 最稳。

怎么更新？怎么彻底卸载？

直接安装新版本覆盖即可（签名一致），设置和点位都会保留，不用先卸载。

卸载和普通 App 一样。助手写在 app 私有目录里的日志和截图，卸载时会一起清掉。
